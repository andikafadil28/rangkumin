# Commercial Services / Layanan Komersial

[Bahasa Indonesia](#bahasa-indonesia) | [English](#english)

## Bahasa Indonesia

Core Rangkumin tersedia dengan lisensi [MIT](LICENSE), termasuk hak untuk menggunakan, memodifikasi, dan mendistribusikannya untuk tujuan komersial.

Layanan berbayar dapat ditawarkan secara terpisah, antara lain:

- bantuan setup dan deployment Cloudflare;
- custom branding dan pengembangan fitur;
- dukungan prioritas dan maintenance;
- add-on privat atau managed service berdasarkan perjanjian terpisah.

Pembelian layanan tidak diperlukan untuk menggunakan hak yang diberikan oleh lisensi MIT. Komponen komersial atau proprietary, jika ada, wajib diberi lisensi dan scope terpisah secara eksplisit. Nama serta identitas visual Rangkumin tidak otomatis dilisensikan sebagai merek dagang oleh lisensi MIT.

Hubungi maintainer melalui profil GitHub [@andikafadil28](https://github.com/andikafadil28) untuk kebutuhan komersial. Dokumen ini bukan nasihat hukum; perjanjian komersial final sebaiknya ditinjau penasihat hukum.
